G2 Editor - Nord Modular G2 editor
==================================

INSTALL
1. Drag "G2 Editor" onto the Applications folder in this window.
2. Launch it from Applications.

IF MACOS BLOCKS THE APP
The app is not notarized by Apple, so macOS may refuse to open it
on first launch:

- "unidentified developer":
  Right-click the app icon -> Open -> confirm.

- "damaged and can't be opened":
  Open Terminal and run:

    xattr -cr "/Applications/G2 Editor.app"

  Then launch the app normally.
