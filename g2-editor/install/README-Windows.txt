G2 Editor - Nord Modular G2 editor
==================================

Click "I Agree" to continue. (This is not a license.)

USB DRIVER (WinUSB)
The editor needs the WinUSB driver for the G2. The first time, the
editor shows "USB Driver Problem": click "Install G2 driver" and allow
the administrator prompt.

This replaces Clavia's original driver; the original Clavia editor
won't work until you reinstall that driver.

Windows 11 may block the self-signed WinUSB driver, and Windows may
restore the Clavia driver later. For both, and for installing the
driver by hand with Zadig, see:
https://janburp.github.io/NordModularG2-Editor/getting-started/windows-driver
