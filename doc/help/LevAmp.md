# LevAmp - Amplifies or attenuates an incoming control signal.

GAIN KNOB
Set the amount of amplification/attenuation. Range: 0-127 units.

INPUTS
In1: The signal to be amplified/attenuated.

OUTPUT(S)
Out1: The resulting amplified/attenuated signal.

Note: A gain of 64 units corresponds to "unity" (no change in level).
