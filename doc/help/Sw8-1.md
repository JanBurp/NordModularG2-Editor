# Sw8-1 - Eight-input switch with channel select buttons

## Overview

The Sw8-1 is a switch with eight signal inputs, each with an attenuator, one output, and eight Channel Select radio buttons. The buttons can be labelled for easy identification.

## Inputs

- **Input 1–8** — Signal inputs with individual attenuators

## Controls

- **Channel Select 1–8** — Radio buttons to select which input is routed to the output. Only one channel can be active at a time. Buttons can be labelled.

## Output

- **Out** — Switched signal output (the currently selected input)
