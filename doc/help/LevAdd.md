# LevAdd

Adds or subtracts a constant value to/from an incoming control signal.

## Parameters

- **Add Value**: Sets the value to add/subtract (-64 to +63)
- **Add/Subtract**: Toggle between adding or subtracting the value

## Inputs

| Port | Description |
|------|-------------|
| In1 | Signal to be modified |

## Outputs

| Port | Description |
|------|-------------|
| Result | Modified signal |
