# NoteSend

Sends MIDI Note messages to external devices or software.

## Parameters

**Note Number** — Sets the note number to send (0–127).

**Velocity** — Sets the note velocity (0–127).

**Channel** — Sets the MIDI channel (1–16).

## Outputs

Connects to modules that send MIDI data externally.

## Description

Sends MIDI Note messages to trigger notes on external MIDI devices or software.
