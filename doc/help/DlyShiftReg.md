# DlyShiftReg

Combines delay with a shift register for unique rhythmic effects.

## Parameters

### Time

Sets the delay time. Range: 0.1ms-2000ms.

### Stages

Sets the number of stages. Range: 1-8.

### Feedback

Sets the feedback amount. Range: 0-100%.

### Mix

Sets the dry/wet mix. Range: 0-100%.

## Inputs

### In1

Audio input.

## Outputs

### Out1

Processed audio output.

## Note

Creates unique rhythmic delay patterns.
