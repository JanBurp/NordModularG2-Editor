# Mix4-1A - Four-input mixer with per-channel attenuation and mute

## Overview

The Mix4-1A is a four-channel mixer with individual channel controls and one mixed output.

## Inputs

- **Input 1** — DYNAMIC CONTROL/AUDIO signal input with dedicated attenuation control
- **Input 2** — DYNAMIC CONTROL/AUDIO signal input with dedicated attenuation control
- **Input 3** — DYNAMIC CONTROL/AUDIO signal input with dedicated attenuation control
- **Input 4** — DYNAMIC CONTROL/AUDIO signal input with dedicated attenuation control

## Controls

- **Attenuation knob** (per channel) — Adjusts the level of the corresponding input signal
- **Channel Mute button** (per channel) — Enables or disables the input signal; buttons can be labelled for clarity

## Output

- **Mix Out** — Combined output of all four channels after attenuation and mute processing
