# Mix1-1A

**Group:** In/Out

## Description

This mixer has one DYNAMIC CONTROL/AUDIO signal input, a chain input and one output. The mixer has a Channel Mute button for enabling/disabling the input. The Channel Mute button can be labelled.

## Inputs

**In** (purple)
DYNAMIC CONTROL/AUDIO signal input.

**Chain** (purple)
Chain input for connecting to another mixer.

## Outputs

**Out** (purple)
Mixer output.

## Parameters

**Lev** (MixLevel)
Attenuator or mixer knob for adjusting the input level.

**On** (OffOn)
Channel Mute button. Blue color indicates On, gray indicates Mute. Can be labelled.

**ExpLin** (ExpLin_2)
Sets the curve to Exponential, Linear, or dB scale.
