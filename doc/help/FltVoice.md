# FltVoice (Voice Filter)

The Voice Filter module simulates the part of the vocal tract that produces vowels. You can select between preset vowels (E, I, O, U, Y, AA, AE, OE) and modulate them to generate vocal-like effects. Waveforms with many overtones (sawtooth, pulse) work best. Adding light Saturation distortion to the filter output enhances the effect.

## Parameters

### RES Knob

Emphasizes the frequency peaks of the vowels. More resonance makes the vowels appear more clearly. Reset to medium value by clicking the green triangle above the knob.

### FREQ Knob

Sets the initial center frequency offsets of the vowels. Turning this knob is similar to pitch-shifting a sampled voice. Reset to medium value by clicking the green triangle above the knob.

### FREQ MOD INPUT [ATTENUATOR TYPE II]

Modulates the center frequency offset from an external control source. The rotary knob sets the modulation amount.

### VOWEL DISPLAY BOXES

Displays the three selected vowels. Presets: A.

### VOWEL SELECTOR BUTTONS

Selects the vowels to be used. You can select up to three vowels from: A, E, I, O, U, Y, AA, AE, OE.

### VOWEL MOD INPUT [ATTENUATOR TYPE I]

Modulates navigation between the selected vowels. The knob next to the input attenuates the signal level.

### VOWEL NAVIGATOR KNOB

Navigates between the vowels selected with the vowel selectors. Note: This is a transformation function, not a mix function.

### LEVEL Knob

Attenuates the input level. [ATTENUATOR TYPE I]

## Inputs

### AUDIO INPUT

Audio signal input (sawtooth or pulse waves work best).

### FREQ MOD INPUT

Modulates the center frequency offset.

### VOWEL MOD INPUT

Modulates navigation between selected vowels.

## Outputs

### OUTPUT

Filtered audio signal.

## ON/BYPASS

Enables or disables the module.
