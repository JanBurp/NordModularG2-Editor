Reverb

The Reverb module is a stereo reverb with selectable reverb type, time and brightness. The module also features a Dry/Reverb mix control.

Time

Set the reverb time. The time is shown in the display box. Range: 1.1 ms to 17.58 s.

Brightness

Set the high frequency content of the reverberated signal with the knob. Basically this setting simulates distance, softness of the walls, atmospheric damping, etc., depending on the other reverb settings. The most natural range is between 25 and 50.

Dry/Wet

Set the mix of dry and reverberated signal to be sent to the stereo outputs. See also Common FX group parameters.

Type

Select reverb type between Small, Medium, Large and Hall with the drop-down selector.

Note that changing reverb type will force the Sound Engine to recalculate and thus cause a brief moment of silence.
