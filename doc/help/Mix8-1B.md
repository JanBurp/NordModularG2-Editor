# Mix8-1B - Eight-channel mixer with per-channel attenuation and global -6 dB attenuation

## Overview

The Mix8-1B is a mixer with eight DYNAMIC CONTROL/AUDIO signal inputs, one Chain input, and one output. Each input has a separate attenuation control, and a -6 dB button attenuates all inputs by an additional -6 dB.

## Inputs

- **Input 1** — DYNAMIC CONTROL/AUDIO signal input with dedicated attenuation control
- **Input 2** — DYNAMIC CONTROL/AUDIO signal input with dedicated attenuation control
- **Input 3** — DYNAMIC CONTROL/AUDIO signal input with dedicated attenuation control
- **Input 4** — DYNAMIC CONTROL/AUDIO signal input with dedicated attenuation control
- **Input 5** — DYNAMIC CONTROL/AUDIO signal input with dedicated attenuation control
- **Input 6** — DYNAMIC CONTROL/AUDIO signal input with dedicated attenuation control
- **Input 7** — DYNAMIC CONTROL/AUDIO signal input with dedicated attenuation control
- **Input 8** — DYNAMIC CONTROL/AUDIO signal input with dedicated attenuation control
- **Chain** — Chain input for cascading multiple mixers

## Controls

- **Attenuation knob** (per channel) — Adjusts the level of the corresponding input signal
- **-6 dB button** — Applies an additional -6 dB attenuation to all inputs

## Output

- **Out** — Combined output of all channels after attenuation and -6 dB processing
