EqPeak

The Eq1 module offers parametric equalization with controls for center frequency, gain and bandwidth.

Freq

With the Freq knob you change the center frequency. Range: 20 Hz to 16.1 kHz.

Gain

With the Gain knob you change the gain at the center frequency. Range -18 to +18 dB.

BW

Use the BW knob to set the bandwidth around the center frequency. Range 2 to 0.02 octaves.

Level

With the Level knob you attenuate the input signal [Attenuator Type I]. See also Common Filter parameters.
