# Fade2-1

Fader with two inputs and one output, fades between input signals.

## Inputs

- **FADE MODULATION INPUT**: The DYNAMIC CONTROL/AUDIO modulation input of the X-fade module. Connect a modulator here. The amount of modulation is controlled with the knob [ATTENUATOR TYPE I].

## Parameters

- **1/2 KNOB**: With the 1/2 knob you fade the between the two input signals. In the 12 o'clock position the output is silent. See also "Common Mixer parameters".
