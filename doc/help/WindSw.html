WindSw

The Window Switch "closes" when an incoming Control signal value is within the range set with the From and To parameters. When the switch closes, a high logic gate signal is also output from the yellow logic output.

From knob

Set the lower limit where the switch should close. Range: 0.0-64.0 units in steps of 0.5 units. Note: if the From value is higher than the To value, the switch never closes.

To knob

Set the upper limit where the switch should open. Range: 0.0-64.0 units in steps of 0.5 units. Note: if the From value is higher than the To value, the switch never closes.

Gate output

The yellow logic output sends out a high logic gate signal when the switch is closed. See also Common Switch parameters.
