ModAHD

The AHDMod envelope is an Attack-Hold-Decay envelope with control signal inputs for modulating Attack, Hold and Release times. The Shape characteristics of this envelope is fixed to Linear Attack & Exponential Decay/Release.

Tip! This module can be used to create pulses with a modulatable length when the A and D times are set to very short an the Hold is modulated by a varying control signal. See also Common Envelope Generator parameters.
