# Mux8-1 - 8-1 Multiplexer with control signal channel selection

## Overview

The Mux8-1 is a multiplexer with eight signal inputs and one output. The active input channel is selected by a control signal on the Ctrl input.

## Inputs

- **Input 1–8** — Signal inputs
- **Ctrl** — Control signal to select which channel is routed to the output

## Output

- **Out** — Selected signal output (based on Ctrl input value)
