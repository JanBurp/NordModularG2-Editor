DXRouter

The DXRouter module is intended for use with the Operator modules described on Operator. It works exactly like the Algorithm selector on the DX7 synthesizer, i.e. it routes the Operator output signals either to Operator FM inputs or to the audio mix output and allows for different types of FM synthesis.

Feedback

Select the internal feedback amount for the connected Operator. An internal feedback loop is indicated with orange lines in the DXRouter graph. Range 0-7.

Algorithm

Select one of 32 different algorithms (connection paths) for the connected Operator modules. These 32 algorithms corresponds to the factory algorithms of the DX7 synthesizer. The algorithms are shown in the graph.
