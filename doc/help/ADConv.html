ADConv

The ADConv module is an 8 bit A/D converter. It converts a control signal between -64 and +64 units to a ‘two’s complement’ code, where each output represents the weight of one of the bits in the eight bit code. The two’s complement coding means that the D7 output defines if the input signal is positive or negative (it is named the sign bit). The module outputs logic high signals on its outputs depending on the current input signal level. See also Common Logic module parameters.
