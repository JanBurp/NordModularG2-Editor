# Clip (Clip)

This module can produce digital distortion by decreasing the clip level limit(s) below the normal headroom.

## Parameters (alphabetical)

### ClipLev

Sets the initial clip level limit(s). See also "Common Shaper parameters".

### Shape

Toggle switch for the Symmetric and Asymmetric mode. If this is set to 'Asym', only the positive peaks of a signal will be clipped. If this is set to 'Sym', both the positive and the negative peaks of a signal will be clipped.

## Inputs

### In

Audio input.

### Mod

Modulation input for ClipLev.

## Outputs

### Out

Audio output.

## Graph

Visual representation of the clipper characteristics.

## ON/BYPASS

Enables or disables the module.
