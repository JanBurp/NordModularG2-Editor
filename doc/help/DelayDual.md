# DelayDual - Two independent tempo-synced delay lines.

## Parameters

| Knob/Button | Description |
|-------------|-------------|
| TIME A | Delay time for line A. Range: 0.1ms–2000ms |
| TIME B | Delay time for line B. Range: 0.1ms–2000ms |
| SYNC A | Enable tempo sync for line A |
| SYNC B | Enable tempo sync for line B |
| FEEDBACK A | Feedback amount for line A. Range: 0–100% |
| FEEDBACK B | Feedback amount for line B. Range: 0–100% |
| MIX A | Dry/wet mix for line A. Range: 0–100% |
| MIX B | Dry/wet mix for line B. Range: 0–100% |

## Inputs

| Input | Description |
|-------|-------------|
| InA | Input for delay line A |
| InB | Input for delay line B |

## Outputs

| Output | Description |
|--------|-------------|
| OutA | Output for delay line A |
| OutB | Output for delay line B |
