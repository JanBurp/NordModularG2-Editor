# MinMax

Compares two incoming signals and outputs the minimum and/or maximum value.

## Inputs

| Port | Description |
|------|-------------|
| In1 | The first signal |
| In2 | The second signal |

## Outputs

| Port | Description |
|------|-------------|
| Min | The smaller of the two input values |
| Max | The larger of the two input values |

This module is useful for logic operations, limiting signals, or creating dynamic effects.
