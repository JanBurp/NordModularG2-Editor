LevConv

The Level Converter module can be used to change polarity of an incoming signal and then output it at selectable polarity and/or phase-shifted 180 degrees.

BiPol, Pos and Neg radio buttons

Use these radio buttons to "instruct" the module which type of input signal to expect. This is important because otherwise the conversion won’t be what you’d expect. (Of course, you won’t harm the system by selecting the "wrong" signal type).
