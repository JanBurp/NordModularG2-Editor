# EnvADSR (Envelope ADSR)

This is a regular four-stage ADSR (Attack, Decay, Sustain and Release) envelope. The ADSR Envelope is well suited for controlling audio signal amplitude, pitch and filter cut-off frequency, for example.

## Parameters (alphabetical)

### Attack
Envelope Attack time.

### Decay
Envelope Decay time.

### KB
Keyboard trigger on/off.

### NR
Envelope Normal/Retrigger mode.

### OutputType
Output type: Positive, Negative, or Inverted.

### Release
Envelope Release time.

### Shape
Envelope Shape control.

### Sustain
Envelope Sustain level.

## Inputs

### AM
Amplitude modulation input.

### Gate
Gate/trigger input.

### In
Envelope signal input.

## Outputs

### Env
Envelope output.

### Out
Signal output.

## Graph Display

This module includes a graphical envelope display showing the ADSR envelope shape.
