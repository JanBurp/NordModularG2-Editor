# CtrlSend - Send MIDI CC messages to external devices

## Parameters

### CC Number

Sets the CC number to send (0-127).

### Value

Sets the CC value to send (0-127).

### Channel

Sets the MIDI channel (1-16).

## Outputs

### Out

Connects to modules that send MIDI data externally.

## Note

Used to control external MIDI devices from within a patch.
