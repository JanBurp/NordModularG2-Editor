# Automate

Records and plays back control movements over time.

## Record Button
Start/stop recording automation.

## Play Button
Start/stop playback of recorded automation.

## Speed Knob
Set the playback speed. Range: 0.1x–10x.

## Clear Button
Clear the recorded automation data.

## Inputs
- **Trig**: Trigger input for record/playback.

## Output(s)
- **Out1**: The automation control signal.

## Note
Records knob movements and plays them back in sync with the patch.
