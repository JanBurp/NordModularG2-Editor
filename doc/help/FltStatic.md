# FltStatic (Static Filter)

A static filter with selectable modes, frequency and resonance controls. The slope is fixed at 12 dB/octave.

## Parameters

### MODE

Radio buttons to select filter mode: LP (Lowpass), BP (Bandpass), or HP (Highpass).

### FREQ KNOB

Sets the cut-off frequency of the filter.

### RES KNOB

Controls the resonance amount.

### ON/BYPASS

Enables or disables the module.

## Inputs

### IN

Audio signal input to be filtered.

## Outputs

### OUT

Filtered audio signal.
