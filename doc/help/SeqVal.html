SeqVal

This is a sequencer which sends one control signal value for each step. The value for each step is shown in the corresponding display box. In Unipolar mode (the Uni button depressed), the values are displayed in steps of 0.5 units. Every half-step (.5) is indicated by a dot to the right of the full step value. For example, the value 5.5 is displayed as ‘5 .’. There is also a row of Step buttons for sending out a Trig/Gate signal for every step in the sequence. See also Common Sequencer parameters.
