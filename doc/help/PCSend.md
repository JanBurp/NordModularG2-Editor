# PCSend

The Program Change Send module sends MIDI PC (Program Change) messages to external devices or software.

## Parameters

**PROGRAM NUMBER KNOB** — Set the program number to send. Range: 0-127.

**CHANNEL KNOB** — Set the MIDI channel. Range: 1-16.

## Outputs

**OUTPUT(S)** — Connects to modules that send MIDI data externally.

## Notes

Used to switch programs on external MIDI devices.
