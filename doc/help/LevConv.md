# LevConv

Scales an incoming control signal from one range to another.

## FROM LOW/HIGH

Set the lower and upper limits for the input range. Range: 0–64 units in steps of 0.5.

## TO LOW/HIGH

Set the lower and upper limits for the output range. Range: 0–64 units in steps of 0.5.

## INPUT(S)

**In1** — The signal to be converted.

## OUTPUT(S)

**Out1** — The resulting converted signal.
