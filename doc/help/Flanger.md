# Flanger

Creates a flanging effect using modulated delay lines.

## Controls

| Knob | Description |
|------|-------------|
| SPEED | Set the LFO speed. Range: 0.05-10 Hz. |
| DEPTH | Set the modulation depth. Range: 0-100%. |
| FEEDBACK | Set the feedback amount. Range: 0-100%. |
| MIX | Set the dry/wet mix. Range: 0-100%. |

## Inputs

| Port | Description |
|------|-------------|
| In1 | Audio input. |

## Outputs

| Port | Description |
|------|-------------|
| Out1 | Processed audio output. |

## Note

Creates a classic flanging effect with resonant sweeps.
