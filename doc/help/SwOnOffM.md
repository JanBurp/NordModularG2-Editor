# SwOnOffM (Switch On/Off Momentary)

Momentary On/Off Switch for manual triggering. When you click the On button, the switch closes for as long as you hold the button and automatically opens when you release. Ideal for assigning to an ASSIGNABLE BUTTON on the synth panel. If no signal is patched to the input, the output sends the value 64 units when the switch closes. See also "Common Switch parameters".

## Parameters

**On**
Momentary on/off control. Click and hold to close the switch; release to open.

## Inputs

**In**
Control input. When patched, the switch passes the input signal. When unpatched, the output sends 64 units when the switch is closed.

## Outputs

**Out**
Signal output.

**Ctrl**
Control output with display box.

## Channel Select

MIDI channel selector for the switch output.
