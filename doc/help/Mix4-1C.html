Mix4-1C

This mixer has four Dynamic Control/Audio signal inputs, one Chain input and one output. Each input is equipped with a separate attenuation control. The mixer has a Channel Mute button for each channel for enabling/disabling the input. Each Channel Mute button can be labelled. The mixer also has a -6 dB button for attenuating all inputs by another -6 dB. See also Common Mixer parameters.
