# Reverb - Creates spacious reverberation using multiple comb and all-pass filters

## Controls

| Knob | Description |
|------|-------------|
| SIZE | Set the room size. Range: 0-100%. |
| DAMPING | Set the high frequency damping. Range: 0-100%. |
| MIX | Set the dry/wet mix. Range: 0-100%. |

## Inputs

| Port | Description |
|------|-------------|
| In1 | Audio input. |

## Outputs

| Port | Description |
|------|-------------|
| Out1 | Processed audio output. |

## Note

Creates natural-sounding room ambiance and spatial effects.
