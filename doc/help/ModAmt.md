# ModAmt

**Group:** Modulation

## Description

The Modulation Amount module is used to set the amount of modulation applied to a parameter. It is essentially a scaling module for modulation signals. This module is typically used between a modulation source (like an LFO) and a parameter input to control how much influence the modulation has.

## Parameters

**Amount**
Set the modulation amount. Range: -64 to +63 units.

## Inputs

**In1**
The modulation signal.

## Outputs

**Out1**
The scaled modulation signal.
