Common Level module parameters

Input(s)

The Dynamic Control/Audio signal input(s) of the Level modules.

Output

The Dynamic Control/Audio signal (depending on input signal type) output of the Level modules. Signal: Bipolar

BiP/Uni button

Click the Uni(polar) button to change the output signal from bipolar to unipolar. When you switch to unipolar, the Level knob (see below) resolution is doubled.

Level knob

Set the modulation signal level. In unipolar mode (see above), the Level knob resolution is doubled
