# ClkDiv - Clock Divider

Divides an incoming clock signal by a settable ratio.

## DIVISION RATIO KNOB

Set the division ratio. Range: 1-64.

## INPUTS

### Clk
The clock input signal.

## OUTPUT(S)

### Out1
The divided clock signal.

Note: If the division ratio is set to 4, for example, the output will pulse once for every 4 input pulses.
