# DlyStereo

Stereo delay with independent L/R tempo-synced delay lines.

## Parameters

| Knob/Button | Description |
|-------------|-------------|
| TIME L | Left delay time. Range: 0.1ms–2000ms |
| TIME R | Right delay time. Range: 0.1ms–2000ms |
| SYNC L | Enable tempo sync for left channel |
| SYNC R | Enable tempo sync for right channel |
| FEEDBACK L | Left feedback amount. Range: 0–100% |
| FEEDBACK R | Right feedback amount. Range: 0–100% |
| MIX L | Left dry/wet mix. Range: 0–100% |
| MIX R | Right dry/wet mix. Range: 0–100% |

## Inputs

| Input | Description |
|-------|-------------|
| InL | Left audio input |
| InR | Right audio input |

## Outputs

| Output | Description |
|--------|-------------|
| OutL | Left output |
| OutR | Right output |
