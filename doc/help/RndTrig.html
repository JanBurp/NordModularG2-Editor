RndTrig

The random state or random pulse module produces a yellow pulse or gate output signal at a state that is either a logic high or logic low. The output signal can be used directly to trigger yellow Trigger or Gate inputs. Note that when using the output signal as an analog (to a blue or red input) control signal, the output alternates between a logic low or 0 units for the off state and a logic high or +64 units for the on state.
For every new pulse it is decided if it is passed to the output or not, making the output signal equal in on duration to the on duration of the input pulse signal. This means that if gate signals of different lengths are used to clock this module, the length of the current gate signal is left unaltered if the module decides to 'pass' this current clocking gate signal to the output of the module.
