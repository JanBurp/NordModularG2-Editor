# ShpStatic (ShpStatic)

This module distorts a signal using one of four different amplification/attenuation characteristics.

## Parameters

### Shape Buttons

Set the desired transfer curves with the selectors: Inv x3, Inv x2, x2, or x3.

## Inputs

### In

Audio input.

### Mod

Modulation input.

## Outputs

### Out

Audio output.

## Graph

Visual representation of the shaper characteristics.

## ON/BYPASS

Enables or disables the module.
