# StChorus

Stereo Chorus module.

The Stereo Chorus module creates a rich, detuned stereo effect by combining multiple modulated delay lines.

## Controls

| Knob | Description |
|------|-------------|
| SPEED | Set the LFO speed. Range: 0.05-10 Hz. |
| DEPTH | Set the modulation depth. Range: 0-100%. |
| MIX | Set the dry/wet mix. Range: 0-100%. |

## Inputs

| Port | Description |
|------|-------------|
| InL | Left input. |
| InR | Right input. |

## Outputs

| Port | Description |
|------|-------------|
| OutL | Left output. |
| OutR | Right output. |

## Notes

Creates a wide, spacious stereo effect.
