# NoiseGate - Gate an incoming signal based on a threshold level

## Parameters

### Threshold

Sets the threshold level (0-127). When the input signal exceeds this level, the gate opens; when it falls below, the gate closes.

## Inputs

### In1

The signal to be gated.

## Outputs

### Out1

The resulting gated signal.

### Gate Output

A logic signal that goes HIGH when the gate is open. Useful for removing background noise or creating rhythmic effects.
