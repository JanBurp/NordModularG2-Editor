# FlipFlop (Flip-Flop)

The Flip-Flop module is a basic memory cell that can store one bit of information. It toggles its output state when the input signal goes from LOW to HIGH.

## Inputs

### In1

Trigger input. The output toggles on the positive edge (LOW to HIGH transition) of this signal.

## Outputs

### Q

The normal output.

### -Q

The inverted output.
