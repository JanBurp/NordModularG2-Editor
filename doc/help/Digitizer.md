# Digitizer - Digital distortion via bit depth and sample rate reduction

## Parameters

| Knob | Description | Range |
|------|-------------|-------|
| Bit Depth | Sets the bit resolution | 1-16 bits |
| Sample Rate | Sets the sample rate reduction | 1-100% |
| Mix | Sets dry/wet mix | 0-100% |

## Inputs

- **In1** — Audio input

## Outputs

- **Out1** — Processed audio output

## Notes

Creates lo-fi, sample-rate reduction, and digital distortion effects.
