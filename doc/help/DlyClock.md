# DlyClock

Tempo-synced delay module with clock divisions.

## Inputs

- **In1** — Audio input
- **Clk** — Clock input

## Outputs

- **Out1** — Processed audio output

## Controls

- **Division** — Sets the clock division (range: 1/64 to 8 bars)
- **Feedback** — Sets the feedback amount (range: 0-100%)
- **Mix** — Sets the dry/wet mix (range: 0-100%)

## Notes

Delay time is locked to musical divisions of the master clock.
