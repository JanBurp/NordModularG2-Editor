LevMult

The Level Multiplier module performs the same functions as a traditional VCA, a voltage controlled amplifier, in a analog system would do. It multiplies two incoming signals (input 1 times input 2 = output). It also functions as a ring modulator (see example below). See also the LevMod module later in this chapter

inputs

Patch two separate signals to each of the inputs. A signal with a level of 0 units at any of the inputs will close the gain control function, a signal with a level of +64 units at any of the inputs will open the gain control function completely. A signal with a level of -64 units at any of the inputs will invert the polarity of the output signal. See also Common Level module parameters.
