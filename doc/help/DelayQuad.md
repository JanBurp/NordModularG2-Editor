# DelayQuad

Four independent tempo-synced delay lines for complex spatial effects.

## Parameters

| Knob/Button | Description |
|-------------|-------------|
| TIME (×4) | Delay time per line. Range: 0.1ms–2000ms |
| SYNC (×4) | Enable tempo sync per line |
| FEEDBACK (×4) | Feedback amount per line. Range: 0–100% |
| MIX (×4) | Dry/wet mix per line. Range: 0–100% |

## Inputs

| Input | Description |
|-------|-------------|
| In1 | Input for delay line 1 |
| In2 | Input for delay line 2 |
| In3 | Input for delay line 3 |
| In4 | Input for delay line 4 |

## Outputs

| Output | Description |
|--------|-------------|
| Out1 | Output for delay line 1 |
| Out2 | Output for delay line 2 |
| Out3 | Output for delay line 3 |
| Out4 | Output for delay line 4 |
