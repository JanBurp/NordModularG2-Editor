# CompSig

Compresses the dynamic range of an incoming signal.

RATIO KNOB
Set the compression ratio. Range: 1:1 to 20:1.

THRESHOLD KNOB
Set the threshold level. Range: 0-127 units.

INPUTS
In1: The signal to be compressed.

OUTPUT(S)
Out1: The resulting compressed signal.

GAIN REDUCTION OUTPUT
Indicates the amount of gain reduction being applied.

Note: This module reduces the dynamic range of the signal by amplifying quieter parts and attenuating louder parts.
