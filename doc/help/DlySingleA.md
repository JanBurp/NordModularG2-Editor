# DlySingleA

Tempo-synced mono delay with character A (smoother, warmer).

## Inputs

**In1** — Audio input.

## Outputs

**Out1** — Delayed audio output.

## Parameters

**Time** — Delay time. Range: 0.1ms–2000ms.

**Sync** — Enable tempo sync.

**Feedback** — Feedback amount. Range: 0–100%.

**Mix** — Dry/wet mix. Range: 0–100%.
