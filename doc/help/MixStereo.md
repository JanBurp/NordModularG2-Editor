# MixStereo - Six-channel stereo mixer with per-channel attenuation and pan

## Overview

The MixStereo is a stereo mixer with six DYNAMIC CONTROL/AUDIO signal inputs and a stereo output. Each input has a separate attenuation control and a Pan knob. The Pan knobs attenuate the middle of the stereo panorama by -3dB.

## Inputs

- **Input 1** — DYNAMIC CONTROL/AUDIO signal input with dedicated attenuation control and pan
- **Input 2** — DYNAMIC CONTROL/AUDIO signal input with dedicated attenuation control and pan
- **Input 3** — DYNAMIC CONTROL/AUDIO signal input with dedicated attenuation control and pan
- **Input 4** — DYNAMIC CONTROL/AUDIO signal input with dedicated attenuation control and pan
- **Input 5** — DYNAMIC CONTROL/AUDIO signal input with dedicated attenuation control and pan
- **Input 6** — DYNAMIC CONTROL/AUDIO signal input with dedicated attenuation control and pan

## Controls

- **Attenuation knob** (per channel) — Adjusts the level of the corresponding input signal (ATTENUATOR TYPE II)
- **Pan knob** (per channel) — Positions the signal in the stereo field; center position is attenuated by -3dB
- **Master Level knob** — Controls the overall output level of the stereo signal

## Output

- **Out L** — Left stereo output
- **Out R** — Right stereo output
