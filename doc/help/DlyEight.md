# DlyEight - Eight tap delay providing rhythmic delay patterns from multiple taps.

## Parameters

| Knob/Button | Description |
|-------------|-------------|
| TIME | Base delay time. Range: 0.1ms–2000ms |
| TAP LEVEL (×8) | Level for each tap. Range: 0–100% |
| SYNC | Enable tempo sync |

## Inputs

| Input | Description |
|-------|-------------|
| In1 | Audio input |

## Outputs

| Output | Description |
|--------|-------------|
| Out1 | Combined output of all taps |
