# Random Clock A (RndClkA)

The clocked random step module produces a new random value each time it receives a trigger pulse on its Clk input. Use the Dice button to randomize the module manually, instead of using the Clk input.

## Parameters (alphabetical)

### Active
Enables or disables the module. When active, the module processes clock triggers and generates random output values.

### Dice
Manually advances the random generator by one extra step in between the steps generated by the module itself. When assigned to a button on the G2 panel, clicked in the editor program, or assigned to a MIDI CC# that is activated externally or from the patch itself through a MIDI CC# Out module, the module will step to the next position in the sequence.

### OutputType
Controls the output signal range. Bip toggles between unipolar (0 to positive) and bipolar (negative to positive) output modes.

### PolyMono
Selects between polyphonic and monophonic operation modes for the random generator.

### StepProb
Sets the probability percentage for a new random value to be generated on each clock trigger. Lower values produce sparser random events.

## Inputs

### Clk (orange)
Accepts a clock waveform (blue, yellow, or red signal). Every time the signal transitions from a zero or negative value to a positive value, the output of the clocked random generator changes to a new random value.

### Rst (orange)
Reset input. When triggered, resets the random generator to its initial state.

### Seed (purple)
Seed input. Allows external control over the random seed value to produce reproducible random sequences.

## Outputs

### Out (purple)
Outputs the randomly generated value each time a clock trigger is received.
