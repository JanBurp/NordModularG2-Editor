# SeqLev

Outputs a level value that changes over time in a sequence.

## Parameters

**Step Value** (knob, per step 1–8)
Set the level for each step. Range: 0–127 units.

**Clock Mode** (buttons: Free / Tap1–8)
Set the clock mode.

## Inputs

| Port | Description |
|------|-------------|
| Clk  | Clock input |
| Rst  | Reset input |

## Outputs

| Port | Description |
|------|-------------|
| Out1 | Sequenced level signal |

Similar to Value Sequencer but optimized for level control.
