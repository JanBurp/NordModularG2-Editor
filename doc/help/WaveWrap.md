# WaveWrap (WaveWrap) - Amplifies a signal until it hits headroom, then folds/wraps instead of clipping for deep distortion and FM-like characteristics.

## Parameters

- **Wrap** — Sets the initial wrap amount

## Inputs

- **Input** — Audio input
- **Modulation Input** — Modulates the Wrap amount

## Outputs

- **Output** — Wrapped signal output
