# Phaser

Creates a sweeping phase effect by modulating a series of all-pass filters.

## Parameters

### Speed

Set the modulation speed. Range: 0.05-10 Hz.

### Depth

Set the modulation depth. Range: 0-100%.

### Stages

Set the number of phaser stages. Range: 2-8.

### Mix

Set the dry/wet mix. Range: 0-100%.

## Inputs

### In1

Audio input.

## Outputs

### Out1

Processed audio output.

## Note

Creates a swirling, metallic phasing effect.
