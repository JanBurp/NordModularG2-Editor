# SeqVal

Outputs control values in a sequence determined by clock input and step values.

## Parameters

**Step Value** (knob, per step 1–8)
Set the value for each step. Range: 0–127 units.

**Clock Mode** (buttons: Free / Tap1–8)
Set the clock mode.

## Inputs

| Port | Description |
|------|-------------|
| Clk  | Clock input |
| Rst  | Reset input |

## Outputs

| Port | Description |
|------|-------------|
| Out1 | Sequenced value signal |

The sequencer outputs different values for each step, allowing for programmable automation.
