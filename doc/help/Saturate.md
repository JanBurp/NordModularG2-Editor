# Saturate (Saturate) - Logarithmic signal distortion module

## Parameters

**Curve**
Choose between four different transformation curve characteristics. Curve 1 is a smooth logarithmic transformation and Curve 4 is a hard transformation.

**Amount**
Sets the initial shape amount. See also "Common Shaper parameters".

## Inputs

**In**
The audio or control signal input to be shaped.

**Mod**
Modulation input for the Amount parameter.

## Outputs

**Out**
The distorted output signal.

## Common Parameters

**On/Bypass**
Enable or disable the module.

**Graph**
Visual display of the selected distortion curve.
