# LevMod

Creates linear modulation of an incoming signal based on a modulation input.

## OFFSET KNOB

Sets the offset value. Range: 0–64 units.

## AMOUNT KNOB

Sets the modulation amount. Range: -64 to +63 units.

## INPUTS

**In1**: The signal to be modulated.

**Mod**: The modulation signal.

## OUTPUT(S)

**Out1**: The resulting modulated signal.

**Formula**: Out = In1 + (Mod × Amount) + Offset
