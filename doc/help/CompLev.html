CompLev

This module produces a logic signal on its yellow output by comparing a Dynamic Control/Audio signal level to the value set by the knob. If the value of a signal appearing at the input greater than or equal to the value set in the window, the module produces a logic high signal. The logic signal will switch back to low when the incoming signal drops to a level below the set value.

Level limit knob

Set the level limit for the comparison with the knob. Range: -64 to +64 units. The value is shown in the Display Box. See also Common Level module parameters.
