# Mix1-1S

**Group:** Mixer

## Description

This mixer has stereo DYNAMIC CONTROL/AUDIO signal inputs, stereo chain inputs and stereo outputs. The mixer has a Channel Mute button for enabling/disabling the inputs. The Channel Mute button can be labelled.

## Parameters

**Lev** (MixLevel)
Controls the output level of the mixer.

**On** (OffOn)
Click the On/Off button to mute the signal(s) of the mixer. Blue color indicates 'On' and gray 'Mute'.

**ExpLin** (ExpLin_2)
Switches between exponential and linear response characteristics.

## Inputs

**InL** (purple)
Left channel audio/dynamic control input.

**InR** (purple)
Right channel audio/dynamic control input.

**LChain** (purple)
Left channel chain input for feeding signal from another mixer.

**RChain** (purple)
Right channel chain input for feeding signal from another mixer.

## Outputs

**OutL** (purple)
Left channel audio output.

**OutR** (purple)
Right channel audio output.
