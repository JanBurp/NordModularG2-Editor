# PShift

Shifts the pitch of an audio signal up or down semitones while maintaining the original duration. Includes formant control for natural-sounding pitch shifts.

## Inputs

### In1

Audio input for the signal to be pitch-shifted.

## Parameters

### SHIFT

Set the pitch shift amount in semitones. Range: -24 to +24.

### FORMANT SHIFT

Set the formant shift amount. Range: 0–100%.

### MIX

Set the dry/wet mix. Range: 0–100%.

## Outputs

### Out1

Processed audio output with pitch and formant shifting applied.
