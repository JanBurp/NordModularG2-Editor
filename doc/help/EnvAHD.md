# EnvAHD (Envelope AHD)

The Attack-Hold-Decay envelope is an envelope with three stages: Attack, Hold and Release. The AHD Envelope is well suited for audio gating applications, for example. See also "Common Envelope Generator parameters".

## Parameters (alphabetical)

### Attack
Envelope Attack time.

### Decay
Envelope Decay time.

### Hold
Envelope Hold time.

### KB
Keyboard trigger on/off.

### NR
Envelope Normal/Retrigger mode.

### OutputType
Output type: Positive, Negative, or Inverted.

### Shape
Envelope Shape control.

## Inputs

### AM
Amplitude modulation input.

### In
Envelope gate input.

### Trig
Trigger input.

## Outputs

### Env
Envelope output.

### Out
Signal output.

## Graph Display

This module includes a graphical envelope display showing the AHD envelope shape.
