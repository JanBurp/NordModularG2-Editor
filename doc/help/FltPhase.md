# FltPhase (14-Pole Phase Filter)

This is a 14-pole phase filter with peak spread control and adjustable feedback. It features six allpass filters which displace the phase 180 degrees each. The number of allpass filters (1-6) can be selected, giving from one to six notches/peaks.

## Parameters

### SPREAD Knob

Sets the distance between the peaks. Can be modulated from an external source using the blue control signal input and the level attenuator.

### FB Knob

Sets the phaser feedback to the allpass filters. Can be negative or positive. At the 12 o'clock position feedback is zero. Click the green triangle above the knob to set feedback to 0. Can be modulated from an external source using the blue control signal input and the level attenuator.

### NOTCH

Up/down arrow buttons select the number of notches (allpass filters): 1 to 6.

### TYPE

Click to select Notch, Peak, or Deep. In Notch mode, signal notches are attenuated. In Peak mode, signal peaks are amplified. In Deep mode, both notches and peaks are attenuated and amplified.

### LEVEL KNOB

Input level attenuator [ATTENUATOR TYPE I] to the right of the module.

## Inputs

### SPREAD (Blue Control)

External modulation source for peak spread.

### FB (Blue Control)

External modulation source for feedback amount.

## ON/BYPASS

Enables or disables the module.
