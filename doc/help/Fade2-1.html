Fade2-1

This is a fader with two inputs and one output, and a fader rotary knob to fade between the two input signals.

Fade modulation input

The Dynamic Control/Audio modulation input of the X-fade module. Connect a modulator here. The amount of modulation is controlled with the knob [Attenuator Type I].

1/2 knob

With the 1/2 knob you fade the between the two input signals. In the 12 o’clock position the output is silent. See also Common Mixer parameters.
