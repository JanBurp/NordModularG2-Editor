# Sw4-1

Four-input switch with per-channel attenuation and channel select.

## Overview

The 4-1Switch selects one of four input signals to pass to a single output. Each input has its own attenuator, and the active channel is selected via four radio buttons.

## Inputs

- **Input 1** — Signal input with dedicated attenuation control
- **Input 2** — Signal input with dedicated attenuation control
- **Input 3** — Signal input with dedicated attenuation control
- **Input 4** — Signal input with dedicated attenuation control

## Controls

- **Attenuator** (per channel) — Adjusts the level of the corresponding input signal
- **Channel Select** (4 radio buttons) — Selects which input is routed to the output; buttons can be labelled

## Output

- **Out** — The selected input signal after attenuation
