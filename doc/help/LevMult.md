# LevMult

Multiplies two incoming signals. The second signal controls the gain applied to the first.

## Inputs

| Port | Description |
|------|-------------|
| In1  | First signal |
| In2  | Second signal (used as scaling factor) |

## Outputs

| Port | Description |
|------|-------------|
| Out1 | Result of In1 multiplied by In2 |

## Notes

Similar to LevAmp, but gain is controlled by an incoming signal rather than a fixed value. Useful for modulation effects.
