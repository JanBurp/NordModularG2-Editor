# Mux1-8 - 1-to-8 Multiplexer

## Overview

The 1-8Multiplexer routes a single input signal to one of eight outputs. Which output is active is determined by the signal applied to the Ctrl input.

## Inputs

- **In** — Signal input
- **Ctrl** — Control signal that selects which output channel is enabled

## Outputs

- **Out 1–8** — Eight output channels; the active channel is determined by the Ctrl input
