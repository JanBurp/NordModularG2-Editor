# Mix8-1A - Eight-channel mixer with dynamic control/audio inputs and one output

## Overview

The Mix8-1A is a mixer with eight DYNAMIC CONTROL/AUDIO signal inputs and one output. A PAD scroll button allows selection of 0, -6, or -12 dB attenuation on all input channels.

## Inputs

- **Input 1–8** — DYNAMIC CONTROL/AUDIO signal inputs

## Controls

- **PAD scroll button** — Click to select 0, -6, or -12 dB attenuation on all input channels

## Output

- **Out** — Audio/mixed signal output
