# CtrlRcv

**Group:** In/Out

## Description

The Control Receive module receives MIDI CC (Control Change) messages from external controllers or software. Converts incoming MIDI CC messages to control signals within the patch.

## Parameters

**CC Number**
Set the CC number to receive. Range: 0–127.

**Channel**
Set the MIDI channel. Range: 1–16.

## Outputs

**Out1**
The received CC value (0–127).
