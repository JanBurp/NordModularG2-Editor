# MixFader

Eight-channel mixer with per-channel attenuation and mute.

## Overview

The MixFader is an eight-channel mixer with individual channel controls and one combined output. Each channel has a dedicated attenuation slider and mute button. An additional PAD button attenuates all inputs by -6 dB.

## Inputs

- **In 1–8** — DYNAMIC CONTROL/AUDIO signal inputs, each with dedicated attenuation
- **Chain** — Additional input for cascading multiple mixers

## Controls

- **Attenuation slider** (per channel) — Adjusts the level of the corresponding input signal
- **Channel Mute button** (per channel) — Enables or disables the input signal; buttons can be labelled
- **PAD** — Attenuates all eight inputs by an additional -6 dB

## Output

- **Out** — Combined output of all channels after attenuation and mute processing
