Flanger

The Flanger is based on the Nord Electro flanger effect and simulates a vintage type of flanger. The flanger effect is a very characteristic type of "sweep" effect. It’s quite similar to the phaser effect but has a little different characteristics.

Rate

Set the flanger sweep rate. Range: 62.9 s/cycle to 24.4 Hz.
