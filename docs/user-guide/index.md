# Key Commands

⌘ = Ctrl on Windows/Linux. The same list is in the app under **Help → Key Commands**.

## File

| Key | Action |
|---|---|
| `⌘ N` | New patch |
| `⌘ O` | Open file |
| `⌘ S` | Save |
| `⇧ ⌘ S` | Save As |

## Synth

| Key | Action |
|---|---|
| `⌘ G` | Open Synth Settings |
| `⌘ U` | Upload Active Slot |
| `⌘ M` | Send Controller Snapshot |
| `⌘ 1` | Dump One |
| `⌥ S` | Save in Synth |

## Patch & Performance

| Key | Action |
|---|---|
| `⌘ P` | Open Patch Settings |
| `⌘ D` | Download to Slot |
| `⌘ R` | Open Performance Settings (Performance mode) |
| `⇧`+click **Perf** | Toggle Performance mode with SHIFT |

## Edit

| Key | Action |
|---|---|
| `⌘ C` / `⌘ X` / `⌘ V` | Copy / cut / paste selected modules |
| `⌘ A` | Select all modules |
| `⌘ E` | Paste Params |
| `Backspace` | Delete selection (or hovered jack's cable/nest) |
| `⌘ Z` / `⇧ ⌘ Z` | Undo / Redo |
| `⇧`+click module, `⇧`+drag on canvas | Add to selection |
| `⌘`+drag module | Copy module(s) |
| `⌥`+click module | Context menu |

## Slots & Variations

| Key | Action |
|---|---|
| `A`–`D` | Select slot A–D |
| `⌃ Tab` / `⌃ ⇧ Tab` | Cycle to next / previous slot |
| `⇧`+click slot | Toggle slot Active |
| `⌘`+click slot | Toggle slot Keyboard |
| `1`–`8` | Select variation 1–8 |
| `R` | Toggle clock run / stop |

## View & Areas

| Key | Action |
|---|---|
| `V` | Show Voice area (Split if already Voice-only) |
| `F` | Show FX area (Split if already FX-only) |
| `Space` | Show / hide all cables |
| `⌃ Space` | Shake cables |
| `⌘ =` / `⌘ -` / `⌘ 0` | Zoom in / out / actual size |

## Panels

| Key | Action |
|---|---|
| `⌘ L` | Toggle Modules pane |
| `⌘ B` | Toggle Browser pane |
| `⌘ I` | Toggle MIDI CC pane |
| `⌘ J` | Toggle Text pane |
| `⌘ K` | Toggle Keyboard pane |
| `⌘ ,` | Toggle Settings pane |
| `⌘ T` | Toggle Extended Toolbar |
| `⌘ F` | Toggle Parameter Pages |
| `/` | Focus search (Modules / Browser pane) |

## Browser Pane

Active after clicking in the browser.

| Key | Action |
|---|---|
| `↑` / `↓` | Move cursor over banks / folders and items |
| `←` / `→` | Switch Disk / Patches / Performances tab (while no cursor is set) |
| `←` | Collapse bank under cursor / go up one folder (Disk) |
| `→` / `↵` / `Space` | Expand bank / open folder / load item under cursor |
| `Esc` | Reset cursor |

## Modules & Parameters

| Key | Action |
|---|---|
| `M` | Quick add module |
| `⇧ ←→↑↓` | Navigate between modules |
| `←` / `→` | Navigate parameters (original editor's order) |
| `↑` / `↓` | Adjust parameter ±1 |
| `⌥ ↑` / `⌥ ↓` | Adjust parameter ±16 |
| `⇧`+drag knob | Fine adjust |
| `L` | Assign last received MIDI CC to selected parameter |
| `Tab` / `⇧ Tab` | Cycle module category (Module Picker toolbar) |
| `,` / `.` | Select module (Module Picker toolbar) |
| `↵` | Add selected module (Module Picker toolbar) |
| `F1` | Show module help |

## Morph Groups

| Key | Action |
|---|---|
| `⌥ 1`–`8` | Select active Morph Group |
| `⌘`+click parameter | Assign / deassign to active Morph Group |
| `⌘`+drag knob/slider | Set morph range |
| `⌘ ↵` | Assign / deassign selected parameter |
| `⌘ ↑` / `⌘ ↓` | Nudge morph range of selected parameter |

## Overlays (hold)

| Key | Action |
|---|---|
| `F5` | Parameter values |
| `F6` | Morph ranges |
| `F7` | Morph group assignments |
| `F8` | MIDI CC assignments |

## Parameter Pages

| Key | Action |
|---|---|
| `⌥`+drag page cell | Assign it to a canvas parameter or another cell |

## Cabling

| Key | Action |
|---|---|
| `⌘`+click jack / cable | Grab cable(s) to re-route |
| `↵` | Connect armed jack (Click connect mode) / confirm suggested cable |
| `Space` | Cycle to next-best suggested cable (Auto-suggest Cable) |
| `Esc` | Cancel armed jack / suggested cable |

## Other

| Key | Action |
|---|---|
| `Esc` | Close dialog / menu / overlay, or clear search filter |
| `` ⌘ ` `` | Cycle to next device window (macOS) |
