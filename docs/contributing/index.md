# Contributing

You can contribute to the editor in several ways:

- **Development** — see [Technical Reference](../technical/) for architecture and build instructions
- **Testing** — run the editor on your hardware and [report issues](bug-reports)
- **Donations** — help cover coding-agent subscriptions and test hardware: [PayPal](https://www.paypal.com/donate/?hosted_button_id=UZE943PYKY5S6)

For other ideas, feel free to open a GitHub issue or discussion.
