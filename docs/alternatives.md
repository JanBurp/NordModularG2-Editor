# Other Nord Modular G2 Editors

There are a few other open-source approaches to editing the Nord Modular G2. Here is a quick comparison:

|  | **This Editor** | [g2-webeditor](https://github.com/ty-art-ty/g2-webeditor) | [G2-Edit](https://github.com/chrispurusha/G2-Edit) |
|---|---|---|---|
| **Platform** | macOS, Windows (Linux planned) | Any browser | macOS only |
| **Approach** | Electron desktop app + C USB daemon | Browser-only; needs a separate hardware USB bridge | Native macOS app |
| **Open source** | Yes | Yes | Yes |
| **Pros** | Multi-platform; full feature set; active development | No install; runs in any browser | Native macOS feel; potentially faster UI |
| **Cons** | Requires USB driver on Windows | Needs extra hardware bridge to reach the G2; no offline use | macOS only; not cross-platform |

All three projects are open source and free to use.
