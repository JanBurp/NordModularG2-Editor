# Contributing

## Ways to contribute

- **Developing** — pick up an open issue or a roadmap item and submit a PR.
- **Testing** — run the editor with your hardware and report bugs. See the [testing guidelines](docs/testing.md) for what to check and how to report.
- **Other ideas** — if you have suggestions beyond the goals listed in the README, feel free to contact me.

Please avoid requesting features you can't develop yourself or that fall outside the goals described in the [README](docs/README.md).

## Donate

If you can't contribute directly but want to support the work, consider a [donation](https://www.paypal.com/donate/?hosted_button_id=UZE943PYKY5S6). It helps cover subscriptions to coding tools and testing hardware.
